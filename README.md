## 📚 PyTorch 深度學習課程

這是一個關於使用 **PyTorch** 進行深度學習的實踐性課程/學習路徑。本課程旨在幫助學習者從基礎概念過渡到能夠獨立構建、訓練和部署深度學習模型的實戰能力。

-----

### ✨ 課程目標

  * 掌握 PyTorch 的基本張量操作 (**Tensors**)。
  * 理解並能實現常見的 **神經網路架構** (如 MLP, CNN, RNN)。
  * 學會使用 PyTorch 的核心模組，如 `torch.nn`, `torch.optim`, `torch.utils.data`。
  * 能夠處理 **真實世界的資料集**，並進行模型訓練、評估與調優。

-----

### Prerequisites (先決條件)

在開始本課程之前，建議你具備以下知識：

  * **Python 程式設計基礎** (包含基本的資料結構、函數和類別)。
  * **基礎線性代數** 和 **微積分** 概念 (有助於理解深度學習原理)。
  * 熟悉 **Jupyter Notebook** 或其他 Python 開發環境。

-----

### 🛠️ 所需環境與工具

為了運行課程中的程式碼，請確保你的環境中安裝了以下主要套件：

  * **Python 3.x**
  * **PyTorch** (建議安裝帶有 GPU 支援的版本，如果可用)
  * **torchvision** (用於電腦視覺資料集和模型)
  * **numpy**
  * **matplotlib**
  * **pandas** (用於資料處理)
